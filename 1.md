# Ultra-Fast Subgrid Mode - Feature Plan

## Overview
This feature adds a new "Ultra-Fast Subgrid" mode that allows for faster and more efficient navigation within a cell using a held row key plus left-hand keys for subgrid selection. This is implemented as a configurable setting that can be toggled in the settings menu.

## Idea Functionality
[
### Workflow, scenarios
1.  **Initial Grid Activation**:
    *   CapsLock(hold) + Key (e.g., Q/1/2) to activate the grid
    *   Classic grid is always shown first (ghvn), regardless of settings

2.  **Cell Selection(same)**:
    *   Press a column key (e.g., Q)
    *   Press a row key (e.g., L) to select cell "QL"

3.  **Subgrid Mode Options**:
    *   **Tap Row Key(default behaviour)**: Traditional GHBN subgrid appears (2x2 grid)
    *   **But Hold Row Key**: If within a (150ms) physical hold being detected, ultra-fast subgrid being shown with new QWERASDFZXCV keys as being active to navigate within it (3x4 grid). If released > GHVN grid comes back. Simple robust approach with show/hide, without refreshing (right now there is a conflict with jumping to cell if row/collumn being clicked, needs to be resolved)

4.  **Ultra-Fast Subgrid Usage**:
    *   While holding the row key (e.g., L), press any left-hand key (QWERASDFZXCV)
    *   Mouse moves to the corresponding position in the 3x4 grid

### Subgrid Layouts
-   **Traditional**: 2x2 grid with keys G/H/B/N
-   **Ultra-Fast**: 3x4 grid with keys:
    ```
    q w e r
    a s d f
    z x c v
    ```
]
